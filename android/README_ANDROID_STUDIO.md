# 🤖 Android Studio Project — AVARA Music App (APK Builder)

This folder contains the complete, ready-to-build **Android Studio Project** for **AVARA Music App** (`com.avara.music`).

---

## 📱 How to Open & Build APK in Android Studio:

### Step 1: Open Project in Android Studio
1. Open **Android Studio**.
2. Click **Open** (or `File -> Open`).
3. Select the `android` folder located inside your `Avara` project directory:
   `/Users/vikashchoudhary/Desktop/Avara/android`
4. Click **OK**. Android Studio will automatically import Gradle and configure the project.

---

### Step 2: Build Release APK or Run on Phone/Emulator
- **To Run on Phone/Emulator**: Connect your Android phone via USB (or start Emulator) and click the **Run ▶️** button in Android Studio.
- **To Build APK File**:
  1. Click **Build** in the top menu bar.
  2. Select **Build Bundle(s) / APK(s) -> Build APK(s)**.
  3. Once built, click **locate** to get your compiled `app-debug.apk` / `app-release.apk`!
